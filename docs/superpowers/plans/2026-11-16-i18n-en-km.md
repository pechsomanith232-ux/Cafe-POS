# English + Khmer (next-intl) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Locale-prefixed English/Khmer routing for the whole app, with the login page, dashboard, sidebar and POS top bar translated, plus a language switcher.

**Architecture:** next-intl v4. `i18n/` holds routing, request config and locale-aware navigation. `proxy.ts` runs the next-intl middleware first, then the existing login-cookie check. All routes move under `app/[locale]/`. Path-specific `revalidatePath` calls switch to `/[locale]/…` route patterns so both locales refresh.

**Tech Stack:** Next.js 16.4 (App Router, `cacheComponents`, `proxy.ts`), next-intl 4.15, shadcn/ui, Vitest, Playwright, pnpm.

**Spec:** `docs/superpowers/specs/2026-11-16-i18n-en-km-design.md`

## Global Constraints

- Locales `["en", "km"]`, default `"en"`, `localePrefix: "always"`.
- Messages in `messages/en.json` and `messages/km.json` (project root), with identical key sets.
- `app/api/**`, `app/favicon.ico`, `app/manifest.ts`, `app/global-error.tsx` and `app/globals.css` stay at the app root and are not modified (except `globals.css` gaining the Khmer font rule, if needed).
- Keep all existing `next.config.ts` settings: `output: "standalone"`, `distDir`, `cacheComponents`, `partialPrefetching`, `experimental.serverActions.bodySizeLimit: "3mb"`, `turbopack.rules`.
- Use `git mv` for every moved file.
- No business logic, database or styling changes beyond what is listed.
- Read `node_modules/next/dist/docs/` (proxy, cacheComponents) and the installed `node_modules/next-intl` README and types before coding each task. Training-data versions differ.
- pnpm only. Each task ends with `pnpm typecheck` passing.

## Review Focus

1. **A save on a `/km` page must refresh that page.** Path-specific `revalidatePath` calls left on plain paths silently stop refreshing. Pinned by the source guard in Task 4.
2. **Signed-out deep link keeps locale and returns there after login.** `/km/pos` → `/km/login?next=%2Fkm%2Fpos` → back to `/km/pos`. Pinned in Task 2 (proxy unit test) and Task 5 (E2E).
3. **Unprefixed links (`window.open("/receipt/…")`) keep the chosen language.** With a `NEXT_LOCALE=km` cookie, `/receipt/x` → `/km/receipt/x`. Pinned in Task 2.
4. **`/api/*` and files with extensions bypass the proxy.** `/api/health`, `/manifest.webmanifest` and `/icons/icon-192.png` must not be redirected. Pinned in Task 2 (matcher test).
5. **An unknown locale or path is a 404, not a crash.** `/fr/pos` and `/en/nope` return 404 pages. Pinned in Task 5 (E2E).

### Task 2: Merge next-intl into proxy.ts

**Files:**
- Modify: `proxy.ts`
- Test: `tests/unit/proxy.test.ts`

**Interfaces:**
- Consumes: `routing` (Task 1).
- Produces: `proxy(request: NextRequest): Promise<NextResponse> | NextResponse` and `config.matcher`, which must equal `["/((?!api|_next|_vercel|.*\\..*).*)"]`.

- [ ] **Step 1: Write the failing tests** in `tests/unit/proxy.test.ts`. Build requests with `new NextRequest(url, { headers })`; a session is simulated with a `better-auth.session_token` cookie (check the exact cookie name `getSessionCookie` reads in `node_modules/better-auth`).

  | Test | Expectation |
  |---|---|
  | `"/ redirects to /en"` | status 307 or 308, `location` ends with `/en` |
  | `"keeps the locale cookie for unprefixed paths"` | with `NEXT_LOCALE=km` and a session, `/receipt/abc?print=1` → `location` ends `/km/receipt/abc?print=1` |
  | `"signed-out deep link goes to localized login with next"` | `/km/pos` → `location` ends `/km/login?next=%2Fkm%2Fpos` |
  | `"login page is reachable signed out"` | `/km/login` → no redirect (no `location` header) |
  | `"signed-in page passes"` | `/en/pos` with a session → no redirect |
  | `"matcher skips api and files"` | `new RegExp("^" + config.matcher[0].replace("/(", "(") + "$")` does not match `/api/health`, `/manifest.webmanifest`, `/icons/icon-192.png`, `/_next/static/x.js`; does match `/en/pos` |

- [ ] **Step 2: Run** `pnpm exec vitest run --project unit tests/unit/proxy.test.ts`. Expected: FAIL.
- [ ] **Step 3: Rewrite `proxy.ts`.**
  - `const intl = createMiddleware(routing)`.
  - `proxy` calls `intl(request)`. If the response has a `location` header, return it.
  - Otherwise read the locale from the first path segment. If there is no session cookie and the path (minus `/{locale}`) isn't `/login`, redirect to `/{locale}/login?next=<pathname+search>`.
  - Otherwise return the intl response, so its locale cookie and headers are kept.
- [ ] **Step 4: Run** the tests. Expected: PASS. `pnpm test` still passes.
- [ ] **Step 5: Commit** with message `feat(i18n): run next-intl in proxy, keep login redirect`.
